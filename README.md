# 🍔 Burger & Co. — Interactive Smart Menu

منيو إلكتروني تفاعلي لمطعم Burger & Co.، مع سلة طلبات، إرسال مباشر عبر WhatsApp، ولوحة تحكم Admin مدمجة — بدون أي Framework أو Backend.

## 🚀 تشغيل المشروع

المشروع HTML/CSS/JS خالص، بدون build step:

1. افتح مجلد `burger-co`.
2. شغّل `index.html` مباشرة في المتصفح، أو (يُفضّل) استخدم سيرفر محلي بسيط حتى تعمل الصور بشكل صحيح:
   ```
   npx serve .
   ```
   أو
   ```
   python3 -m http.server 8000
   ```
3. لتمرير رقم طاولة تلقائيًا: افتح `index.html?table=12`.

## 💰 تعديل الأسعار والمنتجات

- **من الواجهة:** اضغط على 🔒 في الفوتر → أدخل الرمز `1234` → لوحة التحكم → تبويب **المنتجات**.
- **من الكود مباشرة:** ملف `script.js`، دالة `getDefaultMenuData()` — كل منتج له `sizes[]` بسعر لكل حجم.

## 🎨 تعديل الألوان

ملف `style.css`، أول قسم `:root` — غيّر القيم:
```css
--color-primary:#1A2129;
--color-accent:#D35400;
--color-light:#F4F1EA;
```

## 📲 تعديل رقم واتساب الكاشير

- من لوحة التحكم → تبويب **الإعدادات**.
- أو من الكود: `script.js` → ثابت `DEFAULT_CASHIER_NUMBER` (بالصيغة الدولية بدون +، مثال: `201XXXXXXXXX`).

## 🔑 تعديل رمز دخول الأدمن (PIN)

ملف `script.js` → ثابت `ADMIN_PIN` (القيمة الافتراضية: `1234`).

## 🌍 إعدادات اللغة

كل النصوص موجودة في `script.js` داخل كائن `I18N` (قسمين: `ar` و `en`). لإضافة نص جديد للواجهة أضفه في القسمين معًا واستخدم `data-i18n="key"` في HTML أو `t('key')` في JS.

## ➕ إضافة منتج جديد

من لوحة التحكم → المنتجات → **+ إضافة منتج** → املأ الاسم بالعربي والإنجليزي، التصنيف، رابط الصورة، والأحجام والأسعار → حفظ. التغييرات تنعكس فورًا بدون Reload.

## 🖼️ تغيير الشعار (Logo)

من لوحة التحكم → الإعدادات → رابط شعار المطعم.

## ⚠️ ملاحظات أمان مهمة

هذا المشروع **Frontend فقط** ولا يحتوي على Backend حقيقي. رمز دخول الأدمن (PIN) موجود داخل كود JavaScript، وبالتالي:

- هو **UI Access Control** (لتنظيم دخول لوحة التحكم لغير المخوّلين بالخطأ) وليس **Secure Server Authentication**.
- أي شخص يفتح Developer Tools يمكنه رؤية الرمز في الكود المصدري.
- لأمان حقيقي، يجب نقل تسجيل الدخول وإدارة البيانات إلى Backend + Database في مرحلة لاحقة.

## 🗂️ بنية الملفات

```
burger-co/
├── index.html      ← الهيكل
├── style.css       ← التصميم (ألوان مركزية عبر CSS Variables)
├── script.js       ← البيانات + المنطق + i18n + السلة + الأدمن
├── assets/images/  ← صور المنتجات
└── README.md
```

جميع بيانات المنيو والإعدادات (اللغة، الثيم، رقم الكاشير، تعديلات الأدمن) تُحفظ في `localStorage` — لذلك تبقى محفوظة بعد تحديث الصفحة، ويمكن استبدالها لاحقًا بقاعدة بيانات حقيقية دون إعادة كتابة الواجهة.
